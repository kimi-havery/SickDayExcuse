# SickDayExcuse

Entry for the make.fun bounty [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

![bounty](https://make.fun/badge/u-zeroxfive-the-funniest-sick-day-excuse-37423a36.svg)
![rank](https://make.fun/badge/u-zeroxfive-the-funniest-sick-day-excuse-37423a36/kimi-havery/SickDayExcuse/rank.svg)
![reward](https://make.fun/badge/u-zeroxfive-the-funniest-sick-day-excuse-37423a36/kimi-havery/SickDayExcuse/reward.svg)

`main.py` writes one line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set): the
funniest sick-day excuse, under 200 characters, nothing else.

Run it with:

```sh
python3 main.py
```
